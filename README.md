# M1 Signal Lab

مختبر عربي RTL باستخدام React وTypeScript وVite وTailwind وLightweight Charts. أداة بحث وتعليم فقط؛ لا ينفذ صفقات ولا يتصل بكوتكس ولا يطلب بيانات دخول أو مفاتيح سرية.

## التشغيل

يتطلب Node.js 22 وnpm:

```sh
npm ci
npm run dev
npm test
npm run build
```

## البيانات

تجريبية: 480 شمعة ثابتة مصطنعة لكل أصل، وليست بيانات سوق. الاستيراد محلي في الذاكرة، حتى 50000 شمعة و8MB. لا تحفظ البيانات بعد إعادة تحميل الصفحة. لا يوجد مصدر أسعار مباشر.

```csv
time,open,high,low,close
2026-11-16T08:00:00+03:00,1.08,1.09,1.07,1.085
2026-11-16T08:01:00+03:00,1.085,1.09,1.08,1.082
```

الوقت بداية الشمعة: ISO بمنطقة زمنية ثابتة أو Unix بالثواني UTC، بمحاذاة الدقيقة. يمنع التكرار والترتيب العكسي والحقول الناقصة والتواريخ غير الصالحة. لا تملأ الفجوات. الجداول بمنطقة المصدر؛ محور المخطط UTC. الشموع المستقبلية لا تدخل التحليل حتى اكتمالها.

## الحسابات

`src/data.ts` طبقة البيانات والتحقق. `src/engine.ts` محرك مستقل عن React. EMA يبدأ بمتوسط بسيط ثم معامل 2/(الفترة+1). RSI يبدأ بمتوسط المكاسب والخسائر ثم تنعيم Wilder. البيانات المسطحة RSI=50. الفجوات تعيد تهيئة التحليل؛ لا تصدر إشارة حتى يتوفر مقطع متصل كافٍ.

CALL: السريع أعلى البطيء، RSI>50 و<70، الإغلاق أعلى السريع والشمعة صاعدة. PUT: الشروط المعاكسة، RSI>30 و<50. يمكن تغيير الفترات والحدود. WAIT إذا لم تتحقق جميع الشروط. لا حسابات ثقة أو دقة مضمونة.

الدخول الافتراضي افتتاح الشمعة التالية، أو إغلاق شمعة الإشارة كافتراض قابل للاختيار (لا يعني إمكانية تنفيذ حقيقية بهذا السعر). التقييم الافتراضي إغلاق الشمعة التالية؛ يمكن تعديل مدته. زمن السجل وقت إصدار الإشارة بعد إغلاق الشمعة. الصفقات المتداخلة مستقلة؛ لا يمثل الاختبار إدارة محفظة. لا رسوم ولا انزلاق سعري.

الفوز يضيف الحصة × العائد الصافي، والخسارة تخصم الحصة. تساوي السعرين تمامًا تعادل: استرداد افتراضي أو خسارة قابلة للاختيار. الصفقات ذات الفجوات أو المستقبل غير المتوفر غير محسومة. نسبة الفوز الأرباح/(الأرباح+الخسائر)، تستثني التعادلات وغير المحسومة. نقطة التعادل النظرية 1/(1+العائد)، بافتراض عدم التعادل. التراجع الأقصى أكبر انخفاض في الربح التراكمي من قمته بوحدات الحصة. التعادلات المحتسبة خسارة تؤثر على الربح والتراجع، وتظل منفصلة في نسبة الفوز المعلنة.

تقسيم زمني للتطوير والاختبار، مع تسخين المؤشرات بماضٍ معروف فقط. تُستبعد صفقات التطوير التي تتجاوز الحد. يجب تثبيت القواعد قبل قراءة الاختبار المستقل؛ تغييرها بعد المشاهدة يلغي استقلاله. تصدير CSV يتضمن جميع النتائج الحالية؛ الجدول يعرض آخر 500 نتيجة فقط.

## GitHub Pages

ارفع المشروع إلى مستودع GitHub بفرع `main` واختر Settings → Pages → Source: GitHub Actions. سير العمل `.github/workflows/pages.yml` يثبت الحزم ويجري الاختبارات والبناء وينشر `dist`. يستخدم Vite مسارات نسبية `base: './'` ليناسب صفحات المستودعات. لا حاجة لخادم أو أسرار. يمكن استضافة مجلد `dist` على أي استضافة ثابتة.

## الاختبارات

تشمل حساب EMA ومرجع RSI، عدم إصدار إشارة قبل الإغلاق، ثبات الماضي عند تغيير المستقبل، الفجوات، نهاية فترة التطوير، التعادل والتحقق من CSV. تشغيل الصوت اختياري بعد موافقة المستخدم بزر التفعيل، وللبيانات التجريبية فقط.

## ملف تجربة

`public/examples/demo-m1.csv` ملف مصطنع للتجربة فقط (240 شمعة، UTC)، وليس بيانات سوق. يمكن تحميله من `/examples/demo-m1.csv` في الموقع واستيراده من زر CSV. الملف المستورد يظل بيانات مصطنعة حتى لو عرضت شارة CSV؛ الشارة تعني طريقة الإدخال ولا تثبت مصدر الأسعار أو صحتها السوقية.
